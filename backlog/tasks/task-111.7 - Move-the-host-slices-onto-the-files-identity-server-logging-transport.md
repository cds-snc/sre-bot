## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The host reads its facts and values from the files. Identity (ENVIRONMENT, GIT_SHA, process environment only) and the host's own [server] slice (public_base_url, sre_test_channel_id, webhook_max_body_bytes) become host code in server/configuration/, and from them the app factory builds one frozen HostInfo in contracts/configuration.py that every other layer reads through an accessor. The Slack transport reads command_prefix from its own [slack_transport] table in infrastructure/slack/settings.py; the Notify API-key-leak handler gets [notify_api_key_leak] (channel_id, oncall_group_id) beside the handler. create_app() runs the configuration phase once and the lifespan no longer loads files; uvicorn starts with --factory main:create_app. The dead ServerSettings fields, DevSettings, AppSettings and the module-level settings reads are deleted. The logging slice is already on the files (TASK-111.2). One PR under a human-approved size-gate exception (2026-10-22).
