OQ15 A dry run with any blocker is outcome failed and logs at ERROR, so the operator sees it before switching to apply. Recommended: yes.
OQ16 Numeric legacy severity. The bridge drops a numeric severity (only "sev-0".."sev-4" text maps), but the end-state reader accepts an integral number 0-4 under the same name. Because the job cannot keep a dropped shared-name value apart from the record (OQ13), a legacy item with severity 2 reads as no severity before the upgrade and as SEV2 after it. Recommended: the bridge maps an integral 0-4 number as the reader does (one mapping, same read before and after; +2 LOC, its own test). Alternative: leave it, so the job changes that read (inconsistent), or have the job remove the dropped attribute (loses legacy data).
